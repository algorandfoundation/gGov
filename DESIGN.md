# Algorand — Design System

Derived from *Algorand Brand Guidelines v1* (External). This document translates the brand
guidelines into a practical reference for designers and developers. Following it keeps
Algorand represented consistently, which is what drives brand recognition. The identity is
built for a global audience — flexible across languages, cultures, and accessibility needs.

**Brand line:** *Blockchain that scales with your ambition.*

---

## 1. Brand Foundation

| | |
|---|---|
| **Archetype** | The Algorand Builder — a fusion of *Engineer* and *Liberator*. Pragmatic, logical, curious, hands-on; driven to solve hard problems and believes one person's idea can have lasting, positive impact. |
| **Mission** | To power a world where information has integrity and innovative solutions can scale. |
| **Problem** | Current blockchain technologies are mostly slow, expensive, unreliable, overly complex, and require multiple layers to scale. |
| **Solution** | We enable blockchain solutions at real-world scale. |
| **Positioning** | Algorand is an energy-efficient, quantum-secure, single-layer blockchain with instant finality, consistently high throughput, and low fees. |

### Messaging pillars
Four pillars tell the Algorand story and keep messaging consistent while flexing per channel/audience:

1. **Institutional-grade** — security, decentralization, and scale baked into the protocol.
2. **Exceptional developer experience** — common languages and tools, concierge-level support.
3. **World-class engineering** — engineers and scientists setting new standards for mainstream adoption.
4. **Vibrant ecosystem** — builders tackling real-world problems at global scale.

---

## 2. Voice & Tone

Four tone attributes: **Accessible · Confident · Trustworthy · Engaging**

- **Accessible** — Simplify, don't mystify. Everyday language over jargon; use analogies; show enthusiasm without hyperbole. Never assume pre-existing knowledge.
- **Confident** — Assured yet approachable. Speak from demonstrated knowledge, not opinion. Proud, not boastful; no hype or apology.
- **Trustworthy** — Accurate, transparent, accountable. Back claims with credible data; admit when more info is needed. Don't announce until tested and verified.
- **Engaging** — Proactively seek dialogue. Frame insights as "did you know?" not "I told you so." Value curiosity and inclusivity over being right.

**Default casing:** sentence case. Title case is reserved for proper nouns and attributions.

## 3. Logo

### Elements
- **Logotype** — the Algorand wordmark; the bold "A" is the core identity symbol. Use the logotype in most cases.
- **Logomark** — the iconic "A"; an enduring emblem from which the entire visual identity derives. Use strategically so it complements rather than overwhelms.
- **Foundation lockup** — use the Algorand Foundation logo lockup for official Foundation communications (e.g. quarterly Transparency Reports).

### Color rules
- The **logotype** may only ever appear in one of the brand's **primary colors**.
- The **logomark** may use any shade from the primary palette, as long as **high contrast** is maintained for visibility.

### Clear space & minimum size
- **Clear space** around the logo should mirror the size of the symbol itself.
- **Minimum size:** 24 px or 0.25 in in height.

### Sub-brands
Official sub-brands use consistent lock-ups, respect clear-space rules, and set sub-brand
typography in **Inter Medium**.

### Logo don'ts
Do **not**: break it · scale disproportionately · alter the typography · use unapproved
colors · add a border · add effects · blur · rotate. (The ™ symbol is not required.)
Legibility must always be maintained.

## 4. Typography

### Typefaces
- **Primary — Aeonik.** Weights: Light, Regular, Bold (+ italics). Used to emphasize and amplify copy; adds impact to key messages.
- **Secondary — Inter.** Weights: Regular, Medium, Bold (+ italics). For smaller text and descriptive copy. A Google Font, so it doubles as the substitute for Aeonik when Aeonik is unavailable.

### Multilingual fonts
Recommended fonts for non-Latin scripts (sample, not exhaustive):

| Script | Font |
|---|---|
| Latin | Aeonik / Inter |
| Cyrillic | Noto Sans |
| Arabic | Noto Sans Arabic |
| Devanagari | Noto Sans Devanagari |
| Korean | Noto Sans Korean (KR) |
| Japanese | Noto Sans Japanese (JP) |

### Hierarchy
| Role | Typeface |
|---|---|
| Brow | Aeonik Regular |
| Headline | Aeonik Bold |
| Subhead | Aeonik Regular |
| Body | Inter Regular |
| CTA | Aeonik Bold |

Aeonik Bold leads for all headlines and CTAs. Body content is set in Inter.

### Type scale
Aeonik and Inter share the same size ramp. Headline line-height is **100%** (Inter H1 is **110%**).

| Level | Size | Line height |
|---|---|---|
| H1 | 62–101 px | 100% (Inter H1: 110%) |
| H2 | 48–52 px | 100% |
| H3 | 36–42 px | 100% |
| H4 | 21–32 px | 100% |
| Body / Paragraph | 18–24 px (never below 16 pt) | 130% |
| Pull quote (Aeonik Bold / Italic) | 24–48 px | 120% |

> Sizes are optimal for web applications (websites, landing pages, docs, PDFs).

### Rules
- Headlines: **Aeonik Bold, sentence case.** Never all-caps or all-lowercase. Keep them short.
- Don't use more than **four** varying sizes in one piece.
- Body copy: **Inter Regular, sentence case, left-aligned.** Never right-align, justify, or center paragraphs.
- For emphasis use **Inter Bold / Semi Bold**, sparingly. Keep highlighted text the same size as body copy; don't bold whole paragraphs.
- **Pull quotes** stand alone — never mixed into paragraph copy.
- Avoid broken/hyphenated words across line breaks.

### Outline type
Aeonik outlines may be used as a graphic element (not as standard typography) — elegant but
always readable. Outlines may use primary and secondary palette colors. See stroke formula in §7.

### Type don'ts
Don't mishmash styles · don't use non-approved fonts (only Inter and Aeonik) · don't tilt or
rotate text · no effects · watch line spacing (not too tight/loose) · always keep text legible.

- Adhere to the approved text/background combinations to guarantee contrast and readability.

  the default.

### Color don'ts
Don't use colored typography with accent colors in the background · don't use more than one
accent color per asset · no gradients · no unapproved typography colors · no dark color
combinations · no transparent colors on photographs · ensure sufficient contrast · no
unapproved colors or combinations.

## 6. Graphic System

The system is built from the shape of the **"A" logomark** — symbolizing both infinite
possibilities and steadfastness. It's versatile and meant to evolve with the brand.

- **Grid / shapes** — distill the "A" into shapes that can be scaled, reflected, rotated, and merged. Always stick to the **angles found in the logo**.
- **Rounded corners** — apply to all shapes for a modern, user-friendly feel (see corner formula in §7).
- **Outlines** — shapes may be used in outline form (follow stroke formula in §7).
- **Combinations** — combine shapes with purposeful logic that reinforces the message (e.g. a "scalability" asset should give a visual sense of scale). Use on clean backgrounds or layered over images; varying size, position, and transparency creates perspective and scale. Shapes can frame photos/video like "windows."

### Code-derived symbols
Code symbols — e.g. `(){}\|<>`, `-+.:;=#`, `@&!$"` — are a brand graphic element that speaks
to the developer audience. Usable in outline or full form, as background elements or to
reinforce messaging. **Any full lines of code shown must be authentic, blockchain-relevant code.**

### Icons
Icons reinforce a concept or project and signal what content is about. The library covers brand
pillars and product features (e.g. Security, Pure Proof-of-Stake, Instant finality, Zero
downtime, Wallet, Token, Network, Ease-of-use) and grows as needed.

- New icons must match the existing **aesthetic, proportions, and line stroke**.
- At **100×100 px**, the icon stroke is **8 pt**.

## 7. Formulas (responsive geometry)

All based on the **shorter side** of the asset in pixels. Examples assume a 1920×1080 asset
(shorter side = 1080).

| Property | Formula | Example (1080) |
|---|---|---|
| Margins | shorter side ÷ 9 | 120 px |
| Corner radius | shorter side ÷ 72 | 15 px |
| Outline / stroke (max) | shorter side ÷ 540 | 2 px |

- Margins apply to top, bottom, left, and right. **No element** (text, icons, etc.) may sit in the margin.
- If a thinner stroke (0–1 px) is visible at the calculated weight, choose the thinner weight.

---

## 8. Layout

- **Alignment:** left and center alignments are preferred; right alignment is acceptable for some elements to maintain balance.
- Identify the heavy elements first, then compose for balance.
- Text-alignment cohesion: use right or center alignment for headlines; right or justified for body text — always avoiding broken words. (Note: this layout-section guidance differs from the typography section's "body copy is always left-aligned" rule, which governs paragraph copy specifically — follow the typography rule for running paragraph text.)

## 9. Photography

**Overall tone:** bright, colorful, natural, authentic — aligned with the light-and-bright brand.

| Category | Direction |
|---|---|
| **People** | Genuine, confident, inclusive, diverse. Prefer real photos of real people in the Algorand ecosystem (events, conferences) over stock. |
| **Technology** | People interacting with tech + abstract tech imagery; authentic to Algorand/blockchain. Emphasize decentralization and peer-to-peer networks. Match context (hardware for node-operation content; person + phone/laptop for dApp/use-case content). |
| **Community** | Color and vibrance lead. Prioritize community events and community-driven artwork. |
| **Use cases** | Evoke scale, impact, possibility. Include people where appropriate. |

**Avoid:** high or low saturation, black-and-white, very high contrast, sepia tones, heavy
single-color casts, and photos featuring alcoholic drinks.

---

## 10. Brand Application

Apply the system consistently across:

- **Social media** — including PFPs and general-use banners.
- **Data visualization** — follow primary color use, stroke weight, and shape rules; keep it clean and bold with data that's clear and easy to understand.
- **Posters.**
- **Swag** — use primary palette, typography, and symbols for recognizability; accent colors only on smaller pieces. Bake in key brand messages so pieces reward those "in the know" and create a sense of belonging.
- **Stationery.**

Photography (people, technology, community, use cases) · Social media (PFP, general-use banners).
